# 基于 LLM 的自动代理模型辅助的进化算法生成

日期：2026-10-23；版本 0.1.1

**完整在线对照已完成：300 次主实验（60 次在线）、240 次新增模型请求；含消融与复现审计。性能结论以实验报告为准。**


## 1  问题定义与交付边界

### 目标

在有限真实函数评价预算 B 下，最小化确定性黑盒目标 f(x)，其中每个连续变量都有有限上下界。只要求提供 Python callable，不依赖解析梯度。真实昂贵性可以来自仿真、实验或模型训练；本次验证采用解析函数和严格评价次数限制。


### 数学形式

min f(x),  subject to l_j <= x_j <= u_j, j=1,...,d.
归一化变量 z_j=(x_j-l_j)/(u_j-l_j)，在 [0,1]^d 上搜索。历史档案 D_t={(z_i,y_i)}，所有 y_i 都来自真实 objective 调用。输出 argmin_i y_i，不把代理预测值当成实测结果。


### “任意”的操作性解释

任意满足接口约定的有限边界连续单目标问题可以接入；并不意味着任意维度、任意结构或任意预算均有效。一般约束、多目标、离散变量、随机噪声、非平稳目标需要独立适配与验证。当前未实现这些问题的通用求解器。


### 算法生成的边界

LLM 在预定义算法语法内选择代理类型、DE 算子和控制参数，系统校验后通过可信模板导出 Python 程序。结构变化包含模型族与搜索算子，数值变化包含探索和局部搜索强度。它不是无限制生成并执行任意 Python 代码，也没有复现 EoH 的完整算法种群演化。


## 2  代理模型与候选筛选

### 初始设计与数据来源

所有方法先使用同种子、同点数的拉丁超立方采样 LHS。默认 24 个点，预算不足 24 时只评价预算允许的点。代理只使用已真实评价的历史数据，每次选中候选才调用一次真实函数。


### 代理组合与验证

模型候选为高斯核 RBF 回归和含交叉项的二次岭回归。RBF 使用训练集成对距离中位数的 0.5、1、2 倍作为长度尺度候选，正则项 1e-6；二次模型使用增广最小二乘实现 1e-6 岭正则。固定索引 i mod 5=0 为验证集，其余为训练集，选择验证 NRMSE 最小的模型，再用全档案重拟合。


### 采集函数

a(z) = (m(z)-mean(y))/max(std(y),1e-12) - beta * min_i ||z-z_i|| / sqrt(d).
第一项偏向预测目标更低的点，第二项奖励远离已评价数据的覆盖范围。距离是探索启发式，不是经过校准的预测标准差，图中也不把它解释成置信区间。


### 模型管理

默认每新增 3 个真实评价点重新拟合一次；配置改变时立即重拟合。中间使用缓存模型，减少训练开销。验证集来自适应性采样档案，不能视为独立测试集；它只服务于在线模型选择。


### 代理内进化

候选种群由均匀点与当前优秀解周围的高斯扰动组成。DE 在代理采集函数上迭代，候选搜索不消耗真实评价预算。边界用反射修复，交叉至少更新一个维度。最后剔除与真实档案距离不超过 1e-7 的候选，并选择采集值最小者真实评价。


## 3  LLM 设计器与程序生成

### 输入与职责

输入为维度、预算使用量、停滞评价次数、近期相对改进、上一轮验证误差及当前配置；可附加用户问题描述。基准函数名称、已知最优点、目标公式和密钥不会传给模型。LLM 负责低频算法设计，不负责伪造目标函数评价。


### 结构化输出

支持 OpenAI Responses 严格 JSON Schema 输出，以及 DeepSeek Chat Completions 的 JSON Output。DeepSeek 的 JSON 模式不保证 Schema 合法性，两条路径都执行本地 Plan 校验：字段必须齐全，拒绝多余字段、未知算子、非有限数值和越界参数。reason 保存简短决策说明。


### 控制频率与开销

动态模式默认在评价次数 24、44、64、84 时设计，最多 4 次请求。OpenAI 输出上限 1600 token，DeepSeek 为 768 token 且关闭 thinking；均超时 60 秒、不隐式重试。记录实际模型名、response_id、token、耗时和结果。本次完成 60 次动态在线运行、240 次模型请求；全部原始调用、配置事件与真实评价轨迹均随包提交。


### 生成与执行

export_program 将已验证配置以 Python 字面量写入可信模板，生成 solve(problem, budget, seed) 入口。程序从 llm_saea 导入优化内核。模型输出不会传给 eval/exec。动态运行保存完整配置事件；最终导出的冻结配置算法只能复现该配置的行为，不能替代动态事件重放。


### 失败与复现

API 失败、拒绝、响应不完整、JSON 无效或参数越界会明确终止，并保存不含凭据的诊断日志。系统不会悄悄退回离线规则。replay 使用保存的配置事件和原始问题/种子/预算复现本地随机过程，不再次请求 API；重放应单独标注来源。


## 4  接口、配置与复杂度

### 调用方式

安装方法、PowerShell 命令、单次算法生成、动态运行、策略重放及自定义昂贵仿真示例均见 01_python/README.md。普通 saea / de / random / adaptive 运行不需要密钥。在线运行必须显式提供实际可用模型，并安全配置本地密钥。


### 配置默认值

surrogate=auto；operator=current_to_best；mutation=0.65；crossover=0.85；exploration=0.2；local_fraction=0.3；radius=0.12；population=40；generations=6。默认初始样本数 24，真实评价预算 100，重拟合间隔 3。规则自适应方法在连续 12 次无改进时增加探索。


### 成本拆分

总墙钟时间 = 真实函数时间 + 代理训练/搜索时间 + LLM 调用时间 + 程序管理时间。RBF 稠密求解约 O(n^3)，预测约 O(Mnd)；二次特征数 p=1+d+d(d+1)/2，最小二乘代价随 n 和 p 增长。每轮搜索约 population*(generations+1) 个候选。当前无增量矩阵更新或档案压缩，不适合直接推断超高维性能。


### 扩展建议

昂贵确定性仿真可直接替换目标函数。一般约束应明确定义可行性处理与惩罚尺度；整数变量需去重与缓存；噪声函数需重复测量和噪声建模；多目标任务需非支配排序或明确标量化。上述扩展均需独立预算协议，当前交付不声称已验证。


## 5  验证证据与参考文献

### 已执行验证

13 项单元测试覆盖预算、边界、复现、重放、代理、导出、日志和两个服务接口契约。主实验新增 60 次 DeepSeek 在线优化、240 次成功请求，连同 240 次原始离线对照共 300 次运行；另有 60 次冻结消融及 60 次精确事件重放。OpenAI 服务仍未实测。


### 实验结论边界

在线 LLM 已按同预算与初始样本完成五方法对照；结论以实验报告中的真实数据为准。每个实例只有 5 个随机种子，统计能力有限，不能把局部胜出外推为普遍有效。六个解析函数不是实际工业昂贵仿真，当前未验证一般约束、噪声、多目标或离散问题。
