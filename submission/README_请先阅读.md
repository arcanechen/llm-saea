# 基于 LLM 的自动代理模型辅助的进化算法生成

最终提交版；2026-10-23；Python 包版本 0.1.1。

## 三部分交付

1. `01_python`：Python 源码、wheel、可执行示例、13 项测试、实验/审计/文档与打包脚本。
2. `02_documents`：算法说明 PDF/Markdown，流程图 PDF/PNG/SVG/Mermaid。
3. `03_experiments`：最终实验报告、原始数据、在线调用日志、统计表、收敛图及验证记录。

## 实验完成情况

- 主实验：6 函数 × 2 维度 × 5 种子 × 5 方法 = 300 次运行，每次 100 个真实评价，共 30000 次。
- 在线部分：60 次 DeepSeek 动态优化、240 次 API 请求，原始调用证据和用量可查；完整分析位于 `03_experiments/online`。
- 对照来源：240 次既有离线运行完整复用，复制前后哈希一致。`offline` 和 `online` 的这些对照是同一批数据，不得重复计数。
- 补充实验：60 次冻结首次 LLM 配置的本地消融；60 次动态事件精确重放是审计，不作为独立在线样本。
- 原最小接入测试单列于 `deepseek_smoke`，1 次请求 / 866 token，不混入完整在线实验统计。

阅读最终实验报告了解真实排名、配对检验和限制。已完成在线实验不等于证明 LLM 普遍更优；每个实例只有 5 个种子。本实现支持有限边界连续变量、确定性单目标最小化，六个解析基准不等同于真实昂贵工业仿真，未直接验证噪声、多目标、离散或一般约束问题。OpenAI 接口代码保留，但本次真实服务验证使用 DeepSeek。

## 使用和复现

先阅读 `01_python/README.md` 与 `README_DEEPSEEK.md`。安装后可离线运行；在线复现实验需要自行提供有效 API 密钥并支付调用费用。归档不含密钥、私有 env、虚拟环境或缓存。当前工作区私有配置仍位于根目录 `.env.local`。

`SHA256SUMS.txt` 校验包内文件；ZIP 旁的 SHA256 文件校验整个压缩包。未提供姓名、学号或指定命名模板，因此使用项目题目加“最终提交版”命名。
